## Using the manual

1. Open these files in a Markdown viewer that supports GitHub-style heading links, such as a VS Code Markdown preview or a GitHub repository view.
2. Every numbered volume has a contents list and **Start here / Master index / Previous / Next** navigation at the top and bottom.
3. Question references such as **Q193** are clickable. The question bank has category links and individual question shortcuts.
4. The study volume links separately to exercises and their answer key. The final review links essential and hard questions to their corrected answers.
5. Copy or share this entire folder together; its internal links use relative paths and do not depend on the folder's absolute location. If a plain-text editor does not follow links, switch to its Markdown preview.

Source citations in backticks are repository-relative evidence references for the pinned CodeGraph revision. They are not broken manual links or copies of the application source. External documentation links require internet access. Mermaid diagrams need a viewer with Mermaid support; otherwise their diagram definitions remain readable.
